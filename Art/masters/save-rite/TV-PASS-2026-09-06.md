## Cast delivery and honest colour result

All 34 named Save-Rite characters × four walk facings now use the SAME existing filenames under `sprites/save-rite/`, at **228×122**, three **76×122** cells. This corrects the brief's typo calling the cell 76×61. The new player Intern was already at this size and is untouched. Seated facings are untouched.

The approved 552×295 RGB strips were background flood-filled/repaired using the existing pipeline, then each cell was converted to alpha BEFORE premultiplied-alpha Lanczos resampling. No neighbouring-frame filter bleed, quantisation, new poses or silhouette redesign. Existing alignment and frame order are retained: idle 1; walk 0,1,2,1. Garret keeps his clipboard. A final near-key sweep restores **at least 8 points of margin on every nonzero-alpha pixel** because the current game still keys these names. Fully transparent RGB is cleared.

The older claim that raw animation sources would restore missing colour depth did not hold in a six-strip pilot (Anjali and Marguerite, down/up/left). At equal 228×122, raw-source recovery gave slightly FEWER colours and no clear visual gain. These pilot candidates are NOT delivered. The approved strips were retained and correctly resized instead. This is a size/alpha conversion, **not a claim that the colour-depth concern is solved**. It also honours the latest note that animations are good and need no changes.

Before the final tiny key-margin corrections, the delivered-size comparison (alpha ≥128) was Anjali down 6,305 colours, Marguerite down 7,091; office Kyle down 7,667. The seven office down sheets ranged 7,667–13,362 using the same filter/dimensions/alpha threshold. Counts are screening evidence, not aesthetic certification. Full values and the raw recovery pilot are saved locally.

The 136 sheets' decoded pixel cost falls from **84.48 MiB to 14.43 MiB**, excluding any extra keyed canvas. Remove their names from `COLORKEY` when integrating: these are genuine alpha now. Also register new environment props directly as alpha, not keyed; floors remain opaque. This is Claude's code change, not silently done here.
